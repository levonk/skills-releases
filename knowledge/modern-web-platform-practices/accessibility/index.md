# Accessibility

* [Accessibility Coding Guidelines](accessibility.md) - This guide provides actionable DOs and DON'Ts for AI coding agents to ensure web applications are accessible to all users, including those using assistive technologies.

* [Accessible Error Announcement](accessible-error-announcement.md) - Standard HTML5 validation provides visual feedback through :invalid or :user-invalid, but it doesn't automatically synchronize with accessibility attributes like aria-invalid.

* [Accessible generated content](accessible-generated-content.md) - CSS-generated content needs the content property's alt-text argument for screen readers only when the text differs from the primary value and is absent from the DOM; keep meaningful text in the DOM (WCAG F87).

* [Respect Operating System Text Scale](respect-os-text-scale.md) - Users with visual impairments often configure text scaling at the operating system level (such as Dynamic Type on iOS or Font Size scaling on Android/ChromeOS).
