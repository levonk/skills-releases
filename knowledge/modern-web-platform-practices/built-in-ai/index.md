# Built-in AI

* [Language Detection](language-detection.md) - The Language Detector API is a client-side web API designed to identify the language of a given text string. By performing detection locally in the browser, it enhances user privacy and reduces the need for heavy external libraries or costly server-side calls.

* [Language Model](language-model.md) - The Prompt API allows developers to run natural language processing tasks directly in the browser using Gemini Nano. This built-in AI approach ensures user privacy, reduces server costs, and enables offline functionality.

* [Language Model](prompt-api.md) - The Prompt API allows developers to run natural language processing tasks directly in the browser using Gemini Nano. This built-in AI approach ensures user privacy, reduces server costs, and enables offline functionality.

* [Summarizer](summarizer.md) - The Summarizer API allows web developers to offer local, AI-powered text distillation directly within the browser using Gemini Nano in Chrome or Phi in Edge.

* [Translator](translator.md) - The Translator API allows developers to perform client-side text translation using built-in AI models in Chrome and Edge.
