# PWA

* [Installing web applications](install-web-app.md) - Use the Web Install API to give users an explicit, in-page way to install a web application. Installation is always completed through browser-controlled consent UI; websites cannot silently install an app.

* [Migrating the Origin of an Installed Web App](migrate-web-app-origin.md) - Transferring an installed web app (PWA) to a new origin typically requires users to manually uninstall the old app and reinstall the new one.
