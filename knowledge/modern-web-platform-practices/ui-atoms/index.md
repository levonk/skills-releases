# UI Atoms

* [Build Carousel Slide Effects](carousel-slide-effects.md) - Carousel slide effects are a great way to add visual interest to a carousel.

* [Component-specific light/dark themes](component-specific-light-dark-theme.md) - While more commonly set on the root, the color-scheme property can be set on individual elements to force them into a different color scheme from the rest of the page.

* [Using and managing icons](icons.md) - Icon storage and rendering are separate choices. For example, an SVG sprite can supply an icon to the CSS icon system or be referenced with <use>.

* [Position Aware Tooltips](position-aware-tooltips.md) - When building tooltips or popovers with CSS Anchor Positioning, the browser can automatically "flip" the element to a fallback position if it would otherwise overflow the viewport.

* [Pull to Reveal](pull-to-reveal.md) - "Pull to reveal" is a UI pattern where content (such as a search bar or refresh control) is hidden above the top of a scrollable area on initial load, and the user can pull down (scroll up) to reveal it.

* [Responsive tables](responsive-table.md) - Large data tables often become unreadable on small screens as columns overflow or shrink beyond legibility.

* [Scroll Position Aware Elements](scroll-position-aware-elements.md) - Improve the user experience of floating buttons, like a "Back to Top" link, by showing them only when they are useful.

* [Build a Scroll Progress Indicator](scroll-progress-indicator.md) - A scroll progress indicator is a common user interface pattern that visually communicates the user's progress through a scrollable document or container.

* [Scrollability Affordance Hints](scrollability-affordance-hints.md) - Scrollability hints show users that a region has more content in a given direction, and disappear at that end of the content. There are two kinds.

* [Shrinking header on scroll](shrinking-header-on-scroll.md) - A shrinking header on scroll is a common UI pattern where a fixed header element at the top of the page smoothly transitions to a smaller size as the user scrolls down.

* [Single-line text overflow](single-line-overflow.md) - Text that has to stay on one line (tab and chip labels, table cells, sidebar items, file names, media titles) is often longer than its space, especially with user content and translations.

* [State-Aware Sticky Headers](state-aware-sticky-headers.md) - Sticky headers are a common UI pattern, but they often need to change their appearance when they become "stuck" to maintain readability or save space.

* [Viewport-Aware Dropdowns](viewport-aware-dropdowns.md) - A revealed action panel or popover button group is a useful pattern for users to access additional functionality while taking up minimal space.
