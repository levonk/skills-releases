# Minimum Viable Product Manager (MVPM)

The Minimum Viable Product Manager concept, coined by Brandon Chu, defines the
minimum set of skills a product manager needs to be useful on day one. The
framework borrows the "MVP" metaphor from product development and applies it
to the PM role itself: what is the smallest set of competencies that makes a
PM valuable enough to earn the right to grow into the full role?

The MVPM is not a ceiling but a floor. It identifies the baseline below which
a PM cannot function independently, and it is especially useful for hiring
managers evaluating entry-level candidates and for aspiring PMs assessing
their own readiness.

## The MVPM Framework

Brandon Chu's essay defines the minimum viable product manager as someone who
can execute on the core loop of product management: understand the problem,
define the solution, work with the team to build it, and measure the
result.[^chu-mvpm] The framework is deliberately minimal — it does not
require mastery of every PM skill, only enough to be useful and to learn the
rest on the job.
