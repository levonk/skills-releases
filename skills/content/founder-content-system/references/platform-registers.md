# Platform Registers — Starting Points

Each platform has a different register and constraint set. The voice corpus
(Phase 2) captures the founder's per-platform register; the calibrations are
measured per-platform, not carried across. **These are starting points to be
overridden by the client's measured register.** If the founder's corpus shows
a different convention, the corpus wins.

## X (Twitter)

| Attribute | Default |
|-----------|---------|
| Max length | 280 chars (premium: 25,000) |
| Media | Optional; image or short video increases engagement |
| Hashtags | Rare in founder voice; 0–1 per post |
| Links | In a reply, not the main post (links reduce reach) |
| Cadence | 3–7 posts/workweek for an active founder |
| Register | Punchy, conversational, opinion-forward |
| Thread pattern | One hook post + replies for depth; hiring posts put the roles link in a reply |

## LinkedIn

| Attribute | Default |
|-----------|---------|
| Max length | 3,000 chars (1,300 chars before "see more" fold) |
| Media | Narrative posts want a real photo; data posts may use a paper figure or transcript screenshot |
| Hashtags | 3–5 at the end; niche over generic |
| Links | In the first comment, not the body (links reduce reach in the feed) |
| Cadence | 2–4 posts/workweek |
| Register | Longer-form, reflective, professional-but-personal |
| Visuals | Founder-account visuals are working artifacts, never branded design |

## Instagram

| Attribute | Default |
|-----------|---------|
| Max caption | 2,200 chars |
| Media | Required (photo or reel); text-only is not native |
| Hashtags | 5–15; mix broad and niche |
| Links | In bio, not caption (single link via Linktree or similar) |
| Cadence | 3–5 posts/week |
| Register | Visual-first; caption is context, not the main content |
| Reels | Short-form video (15–60s) for reach; captions carry the thesis |

## TikTok

| Attribute | Default |
|-----------|---------|
| Max caption | 2,200 chars (but short captions perform better) |
| Media | Required (video); 15–60s for reach, up to 10 min for depth |
| Hashtags | 3–5; trending + niche |
| Links | Bio only |
| Cadence | 3–7 posts/week for algorithmic momentum |
| Register | Casual, direct-to-camera, trend-aware but not trend-chasing |
| Captions | On-video text for accessibility and silent viewing |

## YouTube

| Attribute | Default |
|-----------|---------|
| Title | ≤60 chars for search; ≤70 chars for click-through |
| Description | First 150 chars is the search snippet; full description below |
| Media | Required (video); thumbnail is critical |
| Hashtags | 3–5 in description; appear above title |
| Links | Cards and end screens; description links for references |
| Cadence | 1–2 long-form/week, or 3–5 shorts/week |
| Register | Educational or narrative; longer attention span than other platforms |
| Shorts | Vertical, ≤60s; repurpose from long-form |

## Facebook

| Attribute | Default |
|-----------|---------|
| Max length | 63,206 chars (but 40–80 chars performs best in feed) |
| Media | Image or video increases reach significantly |
| Hashtags | 0–2; less important than on Instagram/TikTok |
| Links | In-body acceptable; Facebook does not penalize links like LinkedIn |
| Cadence | 1–3 posts/week for a founder page |
| Register | Community-oriented; longer narrative posts work in groups |
| Audience | Often older demographic than Instagram/TikTok |

## Blog (long-form)

| Attribute | Default |
|-----------|---------|
| Length | 800–2,000 words for a standard post; 2,000–5,000 for deep dives |
| Media | Headers, diagrams, embedded media; screenshots for tutorials |
| SEO | Title tag ≤60 chars; meta description ≤155 chars; H1/H2 structure |
| Links | Inline contextual links; external links to primary sources |
| Cadence | 1–2 posts/month for a founder blog; quality over frequency |
| Register | Longest form; full argument with evidence; the source other platforms link to |
| Repurpose | Every blog post seeds 3–5 social posts (one per key insight) |

## Cross-platform rules

- **Platform variants of one story must differ in content and register, not
  just length.** A LinkedIn post shortened to fit X is not an X post — it
  needs a different opening, different register, different media.
- **Sibling posts (same story, two platforms) at least a week apart** to avoid
  the audience seeing the same point twice in quick succession.
- **Two benchmark/research posts never adjacent** — vary the content type
  across the batch.
- **Thesis-sharing posts separated** — if two posts make the same underlying
  point, separate them by at least a week.
- **Launch-window posts placed relative to the launch date** — pre-launch
  teaser, launch-day announcement, post-launch reflection each have their own
  window.
